# Levotrade UI — Proforma Invoice flow

Design screens for the Levotrade export-trade ERP (Mukhi Noordin & Sons), built on the Levotrade design system.

| File | Screen |
|---|---|
| `Main.dc.html` | Home · module quick access |
| `ProformaInvoice.dc.html` | Proforma Invoice list |
| `PIDetail.dc.html` | PI Details (read-only) |
| `AddPI.dc.html` | Add / Edit PI form |
| `CompletePI.dc.html` | Complete PI (pre-filled, fields to fill) |
| `Prototype.dc.html` | Full clickable flow — single source for all screens |

Design system files live in `ds/levotrade/` (tokens + component bundle).
